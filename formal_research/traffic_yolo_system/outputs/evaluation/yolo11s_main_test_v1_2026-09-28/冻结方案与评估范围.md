## 评估口径

主实验评估原始检测器：Ultralytics 标准 detection validator，显式 `split=test`。不加入 ROI、背景确认、跨类别包含框去重、ByteTrack 或交通状态规则。

固定：imgsz=640，batch=8，检测保留 conf=0.001，NMS IoU=0.70，max_det=300，rect=true，augment=false，single_cls=false，agnostic_nms=false，workers=0；四类均纳入，无测试时增强。低分保留用于标准 PR/AP 计算，不使用运行视频时的 conf=0.35 截断来代替 AP 评价。

输出：总体和分类别 Precision、Recall、mAP50、mAP50–95、类别样本量、混淆矩阵、PR/F1 曲线、原生批次标签与预测示例，以及预测 TXT。Precision/Recall 为验证器随 PR 曲线选择的统计工作点，不是固定 conf=0.35 的 micro P/R；其工作点不得回用于调整部署阈值。

本轮不额外运行 n 模型或搜索多个 conf；后续如需预定比较另作记录。尚未完成的交通状态真值验证不属于本轮。
