# 五路口持续时间门槛敏感性分析

**结果：20、30、60 秒三种持续条件已比较完成。** 基于已经生成的五路口10秒状态数据，只改变“条件连续成立多久才产生提示”；数量分位数、运动分位数、证据门槛、10秒窗口和来源保持不变。没有重跑YOLO、修改Unity或读取Main Test。30秒重算的全部逐窗连续时长与提示种类，均与现有状态结果一致。

## 核心结果

下表的计数单位是**区域×10秒窗口**：例如两个道路区域在同一视频时刻都有提示，记作两个区域窗口。它不是独立车辆数，也不是视频中互不重叠的分钟数。“联合提示”是“高数量提示”的子集，不能相加。

| 持续门槛 | 高数量提示区域窗口 | 其中高数量＋相对低运动 | 高数量提示出现段数 | 联合提示出现段数 |
|---:|---:|---:|---:|---:|
| 20秒 | 1,279 | 270 | 435 | 153 |
| 30秒（现用） | 844 | 117 | 284 | 68 |
| 60秒 | 233 | 8 | 89 | 5 |

五路口共22个区域、7,937个区域窗口，其中7,724个所在时间窗完整且未受长保持帧影响；213个区域窗口不用于连续提示。NE12th夜间五区缺乏可区分的数量校准，三种门槛下都没有高数量或联合提示，**不能把零提示解释为畅通**。

| 路口 | 20秒：高数量 / 联合 | 30秒：高数量 / 联合 | 60秒：高数量 / 联合 |
|---|---:|---:|---:|
| Newport | 288 / 62 | 178 / 23 | 37 / 0 |
| NE12th 夜间 | 0 / 0 | 0 / 0 | 0 / 0 |
| Eastgate | 414 / 78 | 293 / 40 | 96 / 4 |
| SE38th | 266 / 69 | 163 / 26 | 27 / 1 |
| NE8th | 311 / 61 | 210 / 28 | 73 / 3 |

## 怎么解释

- **20秒更敏感**：高数量提示从30秒的844增至1,279个区域窗口；联合提示从117增至270。更早出现提示，但更容易把短暂排队或红灯等待纳入。
- **60秒更保守**：高数量提示降至233个区域窗口，联合提示仅8个。较短的变化会被忽略；这并不证明60秒更准确。
- **30秒是现有演示规则**：位于两者之间。上述结果说明提示对持续门槛有明显敏感性，不能仅凭提示多少挑选“最佳”门槛。没有独立拥堵真值，不能计算该门槛的识别准确率、误报率或漏报率。

## 计算边界与复核

仅完整、没有原生长保持帧的10秒窗口可以累积持续时长；窗口不完整、保持帧或条件中断时重置。运动缺失不填0；联合提示要求同一区域“相对高数量”和“相对低图像运动”同时连续成立。提示时间记在满足条件的**窗口结束时刻**，不能提前放到窗口开始。高数量提示可以在运动证据不足时存在，但不代表已确认拥堵。

逐区域的窗口数、提示段数及首次确认时间见 [region_summary.csv](region_summary.csv)；每段提示的首次确认时间见 [first_alert_events.csv](first_alert_events.csv)。[results.json](results.json)保存五个输入状态文件的SHA和完整数字；[analyze.py](analyze.py)是独立复算脚本。每个30秒区域窗口的连续时长、现有高数量提示类别已逐项核对，且同区域中提示窗口数随门槛增加单调不增。

## 明天向老师可以这样说

“I compared 20-, 30-, and 60-second persistence requirements while keeping the detection outputs, region-specific count and motion baselines, and missing-evidence rules fixed. Longer persistence substantially reduced the number of alerts, especially the combined high-count and low-motion hints. This is a sensitivity analysis of the rule, not a measurement of congestion detection accuracy, because independent traffic-state ground truth is unavailable.”

这里比较的是本小时内部校准的**离线提示**。不同摄像机的画面范围、光照、区域尺度和透视不同，区域窗口数不能用来给路口真实拥堵程度排名。20、30、60秒门槛都没有通过状态真值选择为“最优”；是否将这组工程评价作为论文第二目标的评价范围，应在导师会议中明确。
